# Test archives

Small RAR files from libarchive's test suite (https://github.com/libarchive/libarchive, `libarchive/test/`),
uudecoded unchanged and renamed. libarchive is under the BSD-2-Clause license
(https://github.com/libarchive/libarchive/blob/master/COPYING), copyright Tim Kientzle and the libarchive authors.

| File | Source file |
| --- | --- |
| `rar4.rar` | `test_read_format_rar.rar.uu` (RAR 4: a file, a symlink, a folder with a file, an empty folder) |
| `rar5.rar` | `test_read_format_rar5_multiple_files.rar.uu` (RAR 5: four files) |
| `rar5-encrypted.rar` | `test_read_format_rar5_encrypted.rar.uu` (RAR 5, file data encrypted, four files) |
